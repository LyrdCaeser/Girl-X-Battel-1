Cài game lên màn hình chính

  1. Mở trang này bằng trình duyệt có hỗ trợ Thêm vào màn hình chính.
  2. Bấm Chia sẻ, chọn Thêm vào màn hình chính (bật Mở dưới dạng ứng dụng web nếu có).
  3. Thoát trình duyệt, mở biểu tượng GXB 3 vừa tạo để chơi.
